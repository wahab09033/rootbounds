Formally Verified Security Invariants

Invariant 1: Budget Conservation

Allocated ≡ Available + Delegated + Reserved + Spent. Funds cannot be forged, duplicated, or overdrawn across any node in the hierarchy.

Invariant 2: Strict Authority Attenuation

Child permissions can only narrow parent permissions. Child budget ≤ Parent available, Child expiry ≤ Parent expiry, Child recipients ⊆ Parent recipients.

Invariant 3: Hierarchy Depth Ceiling (Max Depth = 3)

Root Vault (Depth 1) → Project Manager (Depth 2) → Researcher/Purchaser (Depth 3). Deep delegation chains are rejected on-chain.

Invariant 4: Instant Cascade Revocation

Revoking an ancestor immediately freezes and paralyzes all downstream descendants across the smart contract.

Invariant 5: Safe Asynchronous Recovery

If a NEAR cross-contract promise fails, reverts, or runs out of gas, in-flight Reserved funds safely restore to Available without fund lockup.
